## 📖 Sobre o Projeto

O **AgroKuvanja** é uma API REST desenvolvida em **Node.js e TypeScript**, para monitoramento e detecção de pragas em campos agrícolas.  
O sistema permite registrar ocorrências, monitorar áreas afetadas e auxiliar na tomada de decisão para controle agrícola.

Este projeto tem como objetivo apoiar a agricultura inteligente 🌾 utilizando tecnologia para melhorar produtividade e reduzir perdas.

---

## 🚀 Funcionalidades

✅ Cadastro de usuários  
✅ Autenticação com JWT  
✅ Registro de áreas agrícolas  
✅ Registro de pragas detectadas  
✅ Monitoramento de ocorrências  
✅ Upload de imagens das pragas  
✅ Relatórios de incidência
